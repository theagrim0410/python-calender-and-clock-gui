# Calendar with Digital Clock

This is a Python-based **GUI Calendar Application** built using **Tkinter**. It allows users to:
- View the **calendar** for a specific month and year.
- See a **live digital clock**.
- Get a **greeting message** based on the current time.
- Exit the application gracefully.

---

##  Features

**Display Monthly Calendar** – Input month and year to view the calendar.
 **Live Digital Clock** – Real-time clock updates every second.
 **Greeting Message** – "Good Morning", "Good Afternoon", etc., based on system time.
 **User-Friendly Interface** – Centered elements with an intuitive design.
 **Input Validation** – Ensures month is between 1-12 and year is between 1800-9999.
 **Exit Button** – Easily close the application.

- **Greeting Message Section**.
- **End & Close Buttons** for interaction.

---

##  Code Structure

- `show()`: Fetches and displays the requested month’s calendar.
- `update_clock()`: Updates the digital clock every second.
- `end()`: Displays a greeting based on the current time.
- `close()`: Closes the application.
